# Переподключение после Apply (Bolt)

[English](reconnect.md) · [Русский](reconnect.ru.md)

После **Применить** (или профиль → устройство) helper пишет `/etc/logid.cfg`,
перезапускает `logid` и при необходимости делает soft USB wake ресивера
Logi Bolt (`046d:c548`).

Если `device_count` всё ещё **0**:

1. GUI запускает фоновый опрос (~2 с, до ~60 с) без блокировки интерфейса.
2. Пошевелите мышь (Easy-Switch на канале Bolt) — часто этого достаточно.
3. Или нажмите **Разбудить ресивер** (`wake-receiver`) для ещё одного soft
   USB reset — опрос продолжится.

Когда устройство появится, строка статуса очищается/обновляется и форма
перечитывается. Статус / батарея опрашиваются примерно каждые **15 с**
(позиции слайдеров не затираются). Слайдеры DPI / SmartShift уходят live
по D-Bus.

Вызовы helper идут в обычном Python-потоке; результат применяется в GUI-потоке
через очередь + `QTimer` (не `QThread`+`Signal→lambda` — иначе виджеты
обновляются не из GUI-потока и PySide6 / Python 3.14 даёт SIGSEGV).
